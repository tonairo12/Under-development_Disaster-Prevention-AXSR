3.遠地地震、噴火などの情報はすこし遅れてでます｡
__________________________________________
--表示される緊急地震速報(EEW)について--
このプロジェクトでは
テレビやスマホで見る緊急地震速報(EEW)とは別に
緊急地震速報 予報を含む情報を表示します、
緊急地震速報 予報は警報と異なり
震度5-以下の震度を予報と含んでおります｡
(一度警報になった場合はそのまま警報が継続されます)
また[予報が発表されたからすぐに知らせる]とかは
しなくて大丈夫です(様子をみて投稿するなど)

またJMA2001走時表を使用して予報円を描画してます｡

--緊急地震速報 (警報)や津波情報などが発表されたら--


1.このプロジェクトをすぐに閉じて身の安全を
守ってください。

2.津波情報(注意報以上)が発表されたら
海岸、川付近から直ちに離れてください、または
高台に避難してください。

3.その情報が発表されて2週間程度は
緊急地震速報や津波に注意すること｡
